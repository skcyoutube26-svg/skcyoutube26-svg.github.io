Talay YouTube

A private analytics tool

Talay YouTube is a private tool used by Shahriar Kamal Chowdhury to read analytics for his own YouTube channels. It is not a public product and is not offered to other people.

The tool asks Google for read-only access to YouTube Analytics (including revenue analytics where available) and basic channel information. It can view this data so it can produce private analytics reports for the channel owner. It cannot upload, edit, comment on, or delete videos, and it cannot change channel settings.

If you reached this page from a Google sign-in screen and you are not Shahriar, you can close the window. This app is not meant for anyone else.
